# Ralph State

`.ralph/` is the durable memory and orchestration state for long-running Antigravity work.

- `IMPLEMENTATION_PLAN.md` — authoritative remaining work.
- `CURRENT_TASK.md` — current bounded iteration.
- `PROGRESS.md` — concise handoff history.
- `RUN_STATE.json` — machine-readable state.
- `DECISIONS.md` — durable architecture/product decisions.
- `KNOWN_ISSUES.md` — reproducible problems.
- `TASK_PROTOCOL.md` — iteration procedure.
- `HANDOFF.md` — prompt for a fresh Antigravity session/account.

Never store credentials or tokens here.
